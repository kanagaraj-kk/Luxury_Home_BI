# Luxury_Home_BI
This project analyzes luxury housing sales data in Bengaluru to uncover market trends, pricing patterns, customer behavior, and sales performance. The data was cleaned and transformed using Python, stored in MySQL, and visualized through interactive Power BI dashboards. The project demonstrates an end-to-end data analytics workflow, including data preprocessing, SQL database management, and business intelligence reporting.
#-Tech Stack
Python (Pandas, NumPy)
MySQL
Power BI
SQL
#-Key Features
Data cleaning and preprocessing
SQL database creation and data management
Interactive Power BI dashboards
Sales and pricing trend analysis
Developer and location-wise performance insights
Business-driven KPI reporting
#-Project Outcome

The dashboard enables stakeholders to analyze luxury housing market trends, monitor sales performance, identify high-performing locations and developers, and support data-driven decision-making in the Bengaluru real estate market.
